# Vahit Ergin — Kişisel Web Sitesi

Saf HTML/CSS/JS ile yapılmış, modern & minimal kişisel portfolyo sitesi.

## Dosyalar
- `index.html` — sayfa içeriği
- `styles.css` — tasarım (açık/koyu tema dahil)
- `script.js` — tema geçişi, animasyonlar
- `.nojekyll` — GitHub Pages'in Jekyll işlemesini atlaması için

## Yerelde açmak
`index.html` dosyasına çift tıkla — tarayıcıda açılır. Kurulum gerekmez.

## Yayınlama (GitHub Pages)
Depo **public** olmalı. Site kaynağı deponun kökü.

Depo → **Settings → Pages → Build and deployment → Source: Deploy from a branch**
→ Branch: `main`, klasör: `/ (root)` → **Save**.

Depo adı `vahitergin.github.io` ise adres https://vahitergin.github.io olur;
başka bir isimse https://vahitergin.github.io/<depo-adi>/ olur.

Her `git push` sonrası site birkaç dakika içinde güncellenir.
